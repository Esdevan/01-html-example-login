# 01-Clase Viernes 14 de Agosto [(Styles)](https://github.com/Esdevan/01-html-example-login/tree/01-clase-viernes-14-agosto)

¡Bienvenidos! En esta sesión comenzamos con la creación de la página de **Login** para nuestro proyecto web, trabajando directamente sobre la estructura y los estilos en HTML.

---

## 📌 Contenido y Avances de la Clase

- **Estructura y Títulos**: Uso y jerarquía de etiquetas de encabezado (`<h1>`, `<h2>`, etc.).
- **Componentes de Formulario**: Implementación de entradas de texto (`<input>`) y botones interactivos (`<button>`).
- **Estilos en Línea**: Aplicación de atributos `style` directamente en componentes y a nivel global dentro del documento HTML.
- **Manejo de Clases**: Organización de estilos utilizando clases CSS dentro del mismo archivo HTML.

---

## 🚀 Próximos Pasos

En las siguientes clases avanzaremos con los siguientes temas:

1. **Modularización de Estilos**: Separación del código CSS en archivos externos específicos (`.css`).
2. **Navegación Web**: Enlace e interacción entre múltiples páginas.
3. **Introducción a JavaScript**: Primeros pasos con scripts para dar dinamismo a la aplicación 🔥.
